# AI Tools Used

I primarily used **ChatGPT (OpenAI)** as an AI-assisted development tool throughout this project.

## How I Used AI

- **Project Design:** Understanding requirements and planning the project structure and Clean Architecture.
- **Development:** Getting guidance on ASP.NET Core, Entity Framework Core, PostgreSQL, React, and Docker implementation.
- **Testing:** Creating and improving backend API tests and frontend UI tests using xUnit, Vitest, and React Testing Library.
- **Debugging:** Identifying and fixing build errors, runtime issues, and configuration problems.
- **Code Review:** Reviewing implementation approaches and improving code quality.

## Verification

AI-generated suggestions and test cases were reviewed and executed before being incorporated into the project.

I verified the implementation through backend builds, PostgreSQL integration and concurrency tests, frontend UI tests, production builds, and ESLint checks.

ChatGPT was used as a development assistant, while implementation decisions and verification remained my responsibility.
